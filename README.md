# UniShare - Student Sharing & Marketplace (frontend only)

Built with HTML5, CSS3 and vanilla JavaScript. No backend, no frameworks.

## Run it
1. Unzip the folder.
2. Double-click `index.html` (opens in your browser).

## Demo account
Email `demo@example.edu` / password `demo123`  (or register your own).

## Files
- `css/style.css` - black & orange theme and components
- `css/responsive.css` - tablet / mobile layout
- `js/storage.js` - localStorage helpers + demo data
- `js/main.js` - navbar, footer and small helpers
- `js/products.js` - home, explore, item details, add-item form
- `js/auth.js` - demo login / register
- `js/dashboard.js` - stats and listing management

## Limits
localStorage works only in one browser. Login here is a demo and is NOT secure.
